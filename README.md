 # 🏪 MinhaLoja v4

Sistema completo de PDV e Análise Preditiva desenvolvido em Python, integrando múltiplos conceitos fundamentais da programação moderna — desde a gestão de objetos até Inteligência Artificial.

## 🚀 Tecnologias e Conceitos Utilizados
- **Python:** Estruturas de controlo, funções e lógica de programação.
- **Orientação a Objetos (OOP):** Modelação de classes (`Produto`) e métodos internos semânticos.
- **SQLite:** Criação e manipulação de bases de dados relacionais para o histórico de vendas.
- **Pandas:** Limpeza, filtragem e agrupamento de dados tabulares.
- **TensorFlow / Keras:** Redes neuronais artificiais para treino supervisionado e previsão de faturamento futuro.
- **Matplotlib / Seaborn:** Construção de gráficos executivos e visualização de tendências.

## 💡 Sobre o Projeto
Este projeto reflete a evolução prática de um sistema comercial automatizado, unindo a vertente de desenvolvimento de software à ciência de dados e machine learning.
